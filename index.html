How to Host on GitHub

1. Make a new GitHub repository.

2. Upload index.html, styles.css, script.js, the assets folder, and .nojekyll.

3. Go to repository Settings → Pages.

4. Under source, choose your main branch and root folder, then save.

Note: This version is 100% static — HTML, CSS, and JavaScript only. There is no backend and no secret API key anywhere.
